# Codex 1.0.10（versionCode 19）

发布日期：2026-10-29

## 交付文件

1. `codex-remote-1.0.10-release.apk`
2. `codex-remote-1.0.10-release.aab`

## 本版内容

1. 输入栏上下文圆圈接入 CC Switch 余额，外环继续表示上下文使用率。
2. 圆心只显示余额整数部分，不显示货币符号、小数和单位。
3. 没有有效余额时保持空圆心，不显示 `0` 或推测值。
4. 圆圈本体缩小为 `34dp`，触控区保持 `48dp`；`320dp` 宽度和 `1.3` 倍字体下不遮挡其他输入栏控件。
5. 点按圆圈仍打开“远端状态”，完整显示当前供应商、余额和单位；无障碍描述同时包含余额整数和上下文百分比。
6. 连接成功和每轮任务结束后自动刷新 CC Switch 余额，不需要先手动打开状态弹窗。
7. SSH 连接增加 30 秒心跳、连续 3 次无响应断线判定和 15 秒连接状态检查。
8. 断线界面明确显示“SSH 连接已断开，请重新连接。”，不再把连接失效误报成 CC Switch 安装或配置失败。
9. 保留 `1.0.9` 及之前版本的中文化、新会话、MiSans、Codex 视觉、通知、图库和协议适配修复。
10. 版本升级为 `1.0.10 (19)`。

## 升级提示

1. `1.0.9` 与 `1.0.10` 使用同一把 Release 签名密钥，满足 Android 覆盖升级条件。
2. 若设备安装的是 Debug 测试包，必须先卸载一次；卸载会清除 App 本地保存的 SSH 连接和凭据。
3. 模拟器测试前卸载了签名不兼容的旧包，因此本次没有验证模拟器本地连接数据在覆盖升级后的保留情况。
