# Codex

通过 SSH 连接服务器上 Codex CLI 的 Android 客户端。

上游项目：[liuhao-labs/codex-remote-android](https://github.com/liuhao-labs/codex-remote-android)

## 功能

- 简体中文界面，内置小米 MiSans 字体。
- 适配 Codex CLI 0.165，并支持 DeepSeek 模型。
- 支持 CC Switch 供应商余额和上下文用量显示。
- 支持从 GitHub Release 检查、下载并校验更新。
- 增加 SSH 心跳与断线检测。
- 适配状态栏、手势区、横屏、键盘安全区和较大字体。
- 顶栏只显示连接状态，模型名称不再重复显示。
