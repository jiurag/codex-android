# Codex Remote Android 1.0.11

上游仓库：[liuhao-labs/codex-remote-android](https://github.com/liuhao-labs/codex-remote-android)

本仓库基于上游适配为简体中文 Android 客户端，不是 OpenAI 官方产品。

## 新增功能

- 完整简体中文界面，内置小米 MiSans 字体。
- 适配 Codex CLI 0.165，并支持 DeepSeek 模型。
- 支持 CC Switch 供应商余额和上下文用量显示。
- 增加 SSH 心跳与断线检测。
- 适配状态栏、手势区、横屏、键盘安全区和较大字体。
- 顶栏只显示连接状态，模型名称不再重复显示。
